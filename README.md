# CivSim

**Civilizations rise, expand, trade and fight on generated terrain.**
Open `index.html` in a browser.

## How it works
- **Terrain** is generated by adding together sine waves at different scales.
- Civilizations **claim nearby tiles** and expand.
- Neighbours can **trade** or go to **war**.
- A civilization collapses only when it is tiny and a much larger enemy dominates it.

## Balancing problems I had
- Civilizations never died, so I made wars more aggressive.
- Then the map became noisy pixels, so I reduced aggression (about ×0.06) and tightened the collapse rule.

## Limits
It is a toy, not a history model. Real civilizations depend on food, disease, ideas and many other things.

## What I learned
Simulation design is mostly balancing. Tiny number changes completely change the result.
